Install on iPhone

  1. Open this app's HTTPS website in Safari.
  2. Tap Share.
  3. Choose Add to Home Screen.
  4. Tap Add. Launch Gym Mode Pro from the new icon.

Installability requires the app to be hosted over HTTPS. This folder alone cannot install itself as an offline PWA.

Delete local data

This permanently deletes saved workouts from this browser. Export a backup first.
